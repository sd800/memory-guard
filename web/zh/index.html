及时发现失控的内存增长。

Memory Guard 守护 Codex 和你选定的其他应用。当某个进程的内存占用异常增长时，它可以暂停或结束这个进程。

01

为什么做 Memory Guard

一次 Codex 任务中，内存占用突然飙升到数十 GB，最终导致整台 Mac 崩溃。Memory Guard 就从这次经历开始。它持续观察你选定的应用及其通过验证的内置辅助进程，找出造成内存增长的那个进程。

  1. 监测结合应用的内存总量和近期增长来判断。占用较高、但保持稳定的应用可以继续运行。
  2. 暂停达到暂停阈值且确认增长异常时，暂停对应进程。该进程已经占用的内存仍然保留。
  3. 结束Codex 默认在暂停两分钟无人处理后强制结束异常进程。若异常增长达到紧急阈值，则立即结束。结束会释放进程占用的内存，也可能丢失当前任务。
02

隐私

Memory Guard 离线即可工作。它读取进程身份和内存计数，每一次判断和保护操作都在你的 Mac 上完成。无需账号，也没有使用分析或用户追踪。

近期采样保存在内存中。守护程序不读取对话、文件内容或源代码。你主动导出的诊断报告只会保存到自己选择的位置。

03

构建 macOS 版
