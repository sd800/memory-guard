01

Why Memory Guard exists

During a Codex session, memory use suddenly climbed into the tens of gigabytes and the Mac crashed. Memory Guard grew out of that incident. It watches the apps you choose and their verified bundled helpers, so it can identify the process driving a spike.

  1. ObserveCompare the app’s combined footprint with recent growth. A stable, memory-heavy app can keep working.
  2. PauseAt the pause threshold, confirmed abnormal growth triggers a pause of the responsible process. It keeps the memory it already holds.
  3. EndCodex defaults to a force-end after two minutes without a response, or immediately if abnormal growth reaches the emergency threshold. Ending releases memory and can lose the current task.
02

Privacy

Memory Guard works offline. It reads process identity and memory counters, and makes every protection decision on your Mac. No account, usage analytics or tracking.

Recent samples stay in RAM. Your conversations, files and source code stay outside the guard’s monitoring scope. Diagnostic exports are saved only to the location you choose.

03

Install Memory Guard

26.11.1 (6) · Apple Silicon · macOS 13+. This build is ad-hoc signed and not notarized, so the first launch may need your approval.

  1. 1. DownloadDownload Memory Guard (.zip, 5.46 MB).
  2. 2. UnzipIn Finder, open Downloads and double-click the ZIP to extract Memory Guard.app. If your browser already extracted it, use that app.
  3. 3. MoveDrag Memory Guard.app into Applications in Finder’s sidebar.
  4. 4. OpenOpen Memory Guard from Applications. If macOS says the developer cannot be verified or Apple cannot check the app, close the alert with Done or OK, keeping the app in place. If it opens normally, skip to step 7.
  5. 5. ApproveOpen Apple menu → System Settings → Privacy & Security. Scroll to Security, find the message about Memory Guard, and click Open Anyway.
  6. 6. ConfirmComplete any authentication macOS requests, such as Touch ID or your Mac login password, then click Open in the confirmation dialog.
  7. 7. ReviewReview the recommended limits in Thresholds. Allow notifications when prompted if you want protection alerts.

If Open Anyway is missing, try opening the installed app again, then return to Privacy & Security. For updates, choose Quit Completely before replacing the installed app.
